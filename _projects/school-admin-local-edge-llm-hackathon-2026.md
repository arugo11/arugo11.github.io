## 概要

`LOCAL×EDGE ローカルLLM / エッジLLM Hackathon` に参加し、学習塾向けの数式ワークシート処理を支援するデモアプリ `school-admin` を開発しました。結果として、`school-admin` が優秀賞を受賞しました。

`school-admin` は、学生向けダッシュボードからワークシート画像をアップロードし、OCR の確認、内容の分析、宿題承認までを一連の流れとして扱う Web アプリです。学習現場での運用を意識しつつ、短期間で実際に動く形までまとめました。

## コンペとの対応

このハッカソンでは、ローカルLLM / エッジLLM を軸に、現場で動く AI のユースケースとデモが重視されていました。`school-admin` では、学習塾の事務・学習支援フローを題材に、ワークシート intake から OCR、分析、承認までをつないだ一連の体験をデモとして提示しました。

## 技術構成

- Backend: FastAPI / Python
- Frontend: React + Vite + TypeScript
- Data: SQLite
- 主な機能: ワークシートのアップロード、OCR確認、分析、宿題承認
